## Current hard truth

Veyra currently demonstrates **expressive workability** across finite shadows and certificate fixtures. It does **not** yet demonstrate a unified alternative mathematics.

The active repository has many executable layers, but most are isolated islands. They are certified by tests on bounded fixtures, not by a shared deductive foundation.

## Non-claims now mandatory

The project must not claim:

1. that Veyra is a complete mathematics;
2. that general Core/VAM semantics are covered by the R10/R11 closed recurrence and observer slices;
3. that Python certificates are formal proofs unless they pass their applicable exact R7–R13 artifact, contract, carrier, elaboration, observer, transport, promotion, and Lean bindings;
4. that topology/geometry/algebra are derived from arithmetic or from one axiom base;
5. that native Veyra ontology is complete beyond the bounded F4 runtime.
6. that the provisional P0 doctrine proves physical/metaphysical reality,
   absolute objectivity, or existence of a completed infinite carrier.
7. that any scoped negative-existence judgment (`EXCLUDED_IN_D_S` or
   checked-absence `ABSENT` in docs 154–156) extends beyond its exact doctrine
   and scope, or that P0 itself contains a `nonexistent` result — the bounded
   P0 slice deliberately has none (`149_positive_ontology_p0.md`); checked
   exclusion is a later doctrine-level addition registered here, and
   evidence-absence `ABSENT`/OPEN never coerces into it.
8. that adoption-conditioned objecthood (a `ScopedObject` requiring an
   `Adopted[D,S]` conjunct, docs 154/155) is an ontological derivation:
   adoption is a governance act by a declared doctrine; it licenses scoped
   bookkeeping identity only, never observer-independent objecthood.

`149_positive_ontology_p0.md` is the canonical P0 statement. Its ideological,
ontological, semantic/epistemic, and governance levels must remain distinct;
the operational F1 axioms and nine mixed Essence policies are not substitutes
for that separation.
`150_constructive_observer_doctrine_p1.md` continues that doctrine without
promotion: finite P1-A2/P3-T relations are not universal observer order;
released E1/E4 roles/tokens are not physical genesis or consciousness;
released C2/C3/C4 and exact-ledger PΩ1/PΩ2 remain independent scoped lanes.
Arithmetic N3/N4 realization/equality are released; N0/N5 and genuine
higher-cell C2.3 are still unreleased/open.

## Repair tracks

### F1 — Unified axiom kernel

Define the smallest executable axiom set for `rez`, `nod`, `tact`, `breath`, `mode`, echo, obstruction, and observer. Every future layer must name which axioms it uses.

### F2 — Theorem language upgrade

The legacy theorem-object lane remains a finite compatibility harness with exact placeholder substitution and fixed evidence class `finite-obligation`. R10 adds a separate source-replayed recurrence proof fragment with:

- quantified variables;
- typed assumptions;
- implications (no `iff` constructor);
- named, canonically serialized propositions and proof terms;
- independent conclusion inference and adversarial artifact replay.

### F3 — Formal proof bridge

R7 checks inference; R8 contracts promotion; R9 transports only the fixed-anchor unary image; R10 proves generic R7/image semantics after Python elaboration. R11 adds `THM-R11-001..006` and a 34-input, nine-stage, eight-object R10-bound bridge for `veyra.observer-core.v2`. Its immutable snapshot-name rows are validated before R10 continuity, filesystem access, or Lean work; a corrupted root blocks all three public paths with zero R10 calls. These bridges bind traced Lean userspace continuity but do not prove Python parsing/codecs, extract Python, or verify the declared OS TCB. Unrelated certificates remain finite evidence.

### F4 — Native runtime

Implemented internal Veyra objects before school shadows. R9 adds a total stack-safe recurrence encoder and exact image transport. R11 adds a closed `input | apply(tail|crest) | pair` AST with branded recurrence/mark/pair responses, ordered `tail-of-silence` obstructions, and `Echo | Mismatch | DomainBlocked`; echo is not equality. This is not arbitrary strict/word-mode semantics or observer synthesis.

### Native number theory track

Move from finite tables to reusable theorems: divisibility laws, infinite-prime analogue or obstruction, factorization principles, and comparisons with classical number theory.

### F5 — Classical benchmark ledger

Implemented first paired ledger in `105_classical_benchmark_ledger_f5.md`:

- classical statement/proof sketch;
- Veyra statement/proof or certificate;
- explicit verdict: shorter, clearer, stronger, weaker, or equivalent;
- honest negative rows when Veyra is weaker or merely equivalent.
