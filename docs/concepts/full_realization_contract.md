# Full Realization Contract

**Registry:** `DEF-376`.

## 1. Non-negotiable target

Veyra is not complete while it only renames school mathematics or recovers it through one observer.

Full realization means:

1. every school concept has a Veyra-native object;
2. every operation declares its observer/echo compatibility;
3. every theorem has executable finite certificates;
4. every shadow theorem states exactly which classical concept is recovered;
5. every obstruction is explicit, not hidden as failure.

## 2. Certification levels

**Level 0 — Shadow recovery.**
Classical school behavior is recovered through a specified observer.

**Level 1 — Veyra-native operation.**
The concept operates on modes/balances/ratios without immediately collapsing to ordinary numbers.

**Level 2 — Echo-safe theorem.**
The operation is proven or tested to respect declared echo tests.

**Level 3 — Counterexample pressure.**
Known false generalizations have recorded witnesses.

**Level 4 — Pedagogical replacement.**
There is a learnable path from primitive intuition to exercises.

## 3. Current required certificate families

The implementation must certify:

- modes and echo tests;
- resonance, defects, weighted costs, and aura-derived costs;
- balance/opposite arithmetic;
- ratio/scale arithmetic;
- dominance/order/intervals;
- linear constraints and obstructions;
- polynomial forms and identities.

## 4. Proof standard

For now, “proof of workability” means:

- unit tests pass;
- CLI smoke examples pass;
- certification script emits a structured report;
- each certified item names the Veyra method used;
- each remaining shadow-level dependency is marked.

This is not the final foundation proof. It is the executable proof harness that prevents self-deception while the system grows.
