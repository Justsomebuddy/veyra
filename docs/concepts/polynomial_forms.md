# Polynomial Ratio Forms

## 1. Purpose

School algebra needs expressions, expansion, multiplication, and factor-like structures.

Veyra treats a polynomial as a reusable **ratio-transform schema** over an unknown mode.

## 2. Definition

**DEF-058 — Polynomial ratio form.**

A polynomial form is a finite coefficient breath:

`P(x)=a₀ ⊕ a₁x ⊕ ... ⊕ aₙxⁿ`

where every `aᵢ` is a ratio mode.

The current external shadow stores coefficients low-degree first.

## 3. Operations

Core 1.9 supports:

- coefficient-wise addition;
- convolution multiplication;
- Horner evaluation;
- formal derivative.

## 4. Interpretation

Polynomial multiplication is the first school-algebra form of weave distribution.

Example:

`(x+1)(x-1)=x²-1`.

This is not yet full Veyra factorization, but it gives executable proof pressure for identities.
