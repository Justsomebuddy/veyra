# Veyra Full Mathematics Roadmap

**Updated:** 2026-08-07
**Status:** active strategic roadmap.
**Goal:** grow Veyra from an executable language kernel into a full alternative mathematics with native objects, proof pressure, computational laboratories, and scientific applicability.

## North Star

Veyra must become a mathematics where the primitive act is not human-style set membership or number equality, but observer-indexed structure: modes, tacts, echoes, obstructions, shadows, lifts, and coverage certificates.

A layer is accepted only when it has:

1. explicit definitions and notation;
2. executable examples;
3. theorem or conjecture cards;
4. counterexample/refutation pressure;
5. Sage-facing or core API surface;
6. tests and certificates;
7. documentation and memory updates.

## Critical foundational blockers

`docs/concepts/foundational_gap_audit.md` is the hard non-claim baseline. R1–R6 add strict witnesses, structural arithmetic, bounded synthesis, and one scoped strength result (`docs/121`–`122`); R7–R10 add one sound recurrence nucleus, exact promotion, fixed-image transport, and closed-source elaboration; R11–R15 add closed observer/echo semantics, one narrow second promotion, bounded synthesis, and comparative evidence (`docs/127`, `139`–`140`). R16 is reduced partial finite calculus rather than a promoted novelty (`docs/141`–`142`, `146`). Veyra is still not unified: general Core/VAM, arbitrary strict/external word modes, proof-core synthesis, and quantum apparatus remain outside; 25 layers are shadows, and Q1–Q11 are finite rows.

P0 (`docs/concepts/positive_ontology_p0.md`) is now the canonical provisional
positive nucleus. It separates ideology, ontology, semantics/epistemology, and
QA without claiming metaphysical proof. P0 formal evidence must precede I2 or another broad domain expansion; its prose alone promotes no layer.
P1 (`docs/concepts/constructive_observer_doctrine_p1.md`) has bounded public evidence;
P1-A implements structural morphisms and P1-A2 exact finite relation laws/classification,
while P1-B/C1/C2/C3/D1/E1 add bounded generability, one fork, exact declared finite catalog confluence, one finite typed translated cell, pointwise productivity, and one OEP-relative role. P1-D2 adds finite-to-universal counterpressure; D3 admits one periodic all-depth family only relative to its exact ledger. PΩ1 and PΩ2 release distinct exact-ledger carriers; higher A2/C/E, productive-to-family passage, and generic AFIP/completion remain unadmitted.
