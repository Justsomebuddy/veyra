# Omega-A: an experimental semantic-authority ladder

**Status:** conceptual note for an unfinished experiment; not a theorem,
stable-Core component, checker release, or authority rule.

## Purpose

Omega-A studies a possible separation between nine distinct obligations:

```text
representation -> preparation -> inert state -> calculus -> quotation
 -> execution -> interpretation -> soundness -> adoption
```

Each arrow introduces a new obligation. None is an automatic cast.

## Proposed levels

### Representation

The KPT, KCA, KCC, KCI, KEB, and KCF prototypes explore finite syntax,
canonical serialization, error offsets, and resource bounds. A successful
round trip would establish only that a finite record has one accepted encoding.
It would not establish provenance, reachability, typing, truth, objecthood, or
infinity.

### Preparation

KIE explores binding a canonical input to an expected finite form and reporting
the first difference. Preparation is not execution, origin evidence, or
acceptance.

### Inert state

A future initial-state layer would organize prepared data without treating a
class name or digest as unforgeable provenance. This layer is not implemented
as a released component.

### Calculus

KEC is an unresolved prototype for bounded bidirectional judgments,
De Bruijn operations, and limited normalization. It does not currently support
a public claim of general normalization, consistency, external truth, or the
existence of a denotation.

### Quotation

A future quotation layer would construct bounded type-directed representations
under explicit resource accounting. A quotation would remain syntax.

### Execution

A future checker would need to replay preparation and every transition,
including refusal, resource, and integrity outcomes. A terminal label alone
cannot establish that the preceding transitions occurred.

### External interpretation

An interpretation must be defined independently of checker acceptance. It
would require explicit non-collapse witnesses, finite adequacy, preservation or
reflection results, and a declared source basis.

### Soundness

A soundness bridge would relate a complete execution trace to the independent
interpretation. No such released theorem is supplied by this experiment.

### Adoption and authority

Even soundness would not automatically adopt an object into Veyra. Adoption
would need a separate scope and source rule. Omega-A currently has no released
authority rule or registry admission.

## Object persistence

A repeated digest is insufficient to establish one persistent object. A future
account would need:

1. a fixed scope and declared observer family;
2. preserving and reflecting translations;
3. coherence between continuations or a named obstruction;
4. historical evidence not borrowed from the result itself;
5. an adoption rule distinct from representation checking.

## Typed silence

The experiment distinguishes several non-success outcomes:

- `ABSENT` — excluded in the stated scope;
- `BLIND` — not distinguished by the observer;
- `UNDEFINED` — no interpretation or operation is defined there;
- `OBSTRUCTED` — a named obstruction is present;
- `UNKNOWN` or `RESOURCE` — no answer within the stated bound;
- `OPEN` — an obligation is stated but not established;
- `UNRESOLVED` — the current rules do not decide the question.

These statuses are not interchangeable without an explicit rule.

## Infinity boundary

Finite prime-power observations and compatible reductions do not by themselves
collapse the following ladder:

```text
finite windows < local extension < productive construction
 < all-depth family hypothesis < completed carrier
```

Moving to an all-depth family requires an additional principle. Moving from a
family to a completed carrier requires another. Existing p-adic work in Veyra
is relative to its exact doctrine and ledger, not a foundation-independent
claim of actual infinity.

## Current boundary

The experimental source is preserved under `experimental/omegaa/`, outside the
installed package and default verification. KCS is unfinished, KEC remains
unresolved, and no complete checker, soundness theorem, production API,
authority rule, object-adoption rule, or Omega-A release is claimed.
