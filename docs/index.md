# Documentation

Veyra is research software, not a completed foundation of mathematics. Start
with the documents that define its claims and boundaries:

- [Manifesto](concepts/manifesto.md)
- [Primitives](concepts/primitives.md)
- [Discovery report](concepts/discovery_report.md)
- [Proof discipline](log/proof_discipline.md)
- [Foundational gap audit](concepts/foundational_gap_audit.md)
- [Package boundary](concepts/package_boundary.md)

The authoritative statement and notation registries live at the repository
root:

- [Theorems](../THEOREMS.md)
- [Notation](../NOTATION.md)
- [Changelog](../CHANGELOG.md)

## Areas

- [`concepts/`](concepts/) contains durable explanations of the mathematical
  and computational model.
- [`reference/`](reference/) contains exact registries, proof notes, notation,
  and the supported `veyra_sage` surface.
- [`log/`](log/) contains bounded experiment and sprint reports.
- [`releases/`](releases/) contains older release history.
- [`tutorials/`](tutorials/) contains practical introductions; start with
  [getting started](tutorials/getting-started.md).

The source layout and verification commands are documented in
[AGENTS.md](../AGENTS.md). Use repository search when looking for a particular
module, theorem identifier, or experiment; this page intentionally does not
duplicate the full file tree.
